# Параллельные вычисления на суперкомпьютере

Проект посвящен исследованию методов оптимизации и распараллеливания вычислительной задачи с использованием технологий OpenMP и MPI. Проведен сравнительный анализ производительности последовательной, оптимизированной и параллельных версий программы.

## Описание задачи

В рамках проекта реализованы пять версий программы для решения задачи:
1. **Исходная последовательная версия** (`var413.c`).
2. **Оптимизированная последовательная версия** (`var413_op.c`) — улучшена локальность данных за счет изменения порядка обхода циклов и передачи массива в функцию.
3. **OpenMP с директивой `for`** (`var413_for.c`) — распараллеливание циклов `relax()`, `init()`, `verify()`.
4. **OpenMP с директивой `task`** (`var413_task.c`) — распределение вычислений между задачами, использование критических секций.
5. **MPI-версия** (`var413_MPI.c`) — декомпозиция матрицы по строкам, обмен граничными строками через `MPI_Sendrecv`, редукции `MPI_Allreduce` и `MPI_Reduce`.

## Структура репозитория

* **`var413.c`** — исходная последовательная программа.
* **`var413_op.c`** — оптимизированная последовательная программа.
* **`var413_for.c`** — OpenMP-версия с `#pragma omp parallel for`.
* **`var413_task.c`** — OpenMP-версия с `#pragma omp task`.
* **`var413_MPI.c`** — MPI-версия.
* **`Отчет1.pdf`** — полный отчет с таблицами и графиками замеров времени.
